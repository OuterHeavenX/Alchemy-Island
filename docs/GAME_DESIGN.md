# Game Design

## Pillars

1. **Experiment without punishment.** Every attempt is quick; failure offers soft feedback.
2. **See knowledge become place.** Major discoveries permanently alter the island.
3. **Wonder before complexity.** A small recipe graph produces a visible arc from wilderness to electricity.

## Core loop

Explore the island → select two known elements → combine → reveal a new element → unlock new recipe branches → watch the island evolve → consult the journal → repeat.

The opening teaches exactly one combination, Earth + Water. After Mud is discovered, the player is free to experiment. The critical path converges through nature, tools, shelter, settlement, metallurgy, and finally Electricity.

## Presentation

The world is a colorful, top-down storybook island with gently animated water, vegetation, characters, fire, raft, farm, and electrical apparatus. The interface pairs parchment, timber, brass, and teal glass tones. Discovery moments use a reveal card, burst particles, generated sound, and brief world change.

## End state

Electricity activates a crude generator and lamp, then presents the vertical-slice completion card. The player can continue exploring afterward.
